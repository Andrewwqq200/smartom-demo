# СмартОм: Умные весы и цифровизация товаров

Аппаратно-программный комплекс для автоматического создания карточек товаров с использованием компьютерного зрения и искусственного интеллекта.

## 🎯 Проблема
Сотрудники складов и курьеры тратят слишком много времени на ручное взвешивание, фотографирование и заполнение характеристик товаров. Это замедляет обработку и приводит к ошибкам ввода данных.

## 💡 Наше решение
Пользователь кладет товар на весы, система делает снимок, распознает товар (название, вес, цвет, материал) с помощью ИИ и автоматически заполняет карточку. Оператору остается только проверить данные и отправить их в базу.

## 🛠 Технологический стек
*   **Frontend:** React, TypeScript, HTML5 Camera API
*   **Backend:** Python, FastAPI, Uvicorn
*   **AI (в планах):** GigaChat Vision / Yandex Vision
