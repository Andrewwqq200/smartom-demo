# СмартОм: приёмка и цифровизация товаров

Прототип для кейса SmartOM. Товар кладут на весы, система снимает вес и фото, читает штрихкод и цвет, проверяет каталог и собирает карточку. Если товар уже известен, карточка сразу уходит в базу приёмки. Если нет, оператор проверяет поля и передаёт запись сам.

## Как это устроено

1. Вес задаётся в граммах. Пока настоящие весы не подключены, на экране есть ползунок: устройство потом передаёт то же число.
2. Когда вес стабилен, камера сама делает снимок. Фото можно снять кнопкой или загрузить файлом.
3. Сервер читает штрихкод, определяет цвет по центру кадра и ищет товар в каталоге.
4. Совпадение по штрихкоду заполняет карточку и записывает приёмку. Совпадение только по цвету или новый товар оператор подтверждает сам.
5. Принятые товары и каталог хранятся в локальной базе `data/smartom.db`.

## Запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

```bash
cd frontend
npm install
npm start
```

Экран откроется на http://localhost:3000, сервер слушает http://localhost:8000.

В каталоге уже есть несколько товаров со штрихкодами. Кнопка «Считать штрихкод» прогоняет картинку кода через тот же адрес `/recognize`, что и снимок с камеры.

## Стек

* Frontend: React, TypeScript, камера браузера
* Backend: Python, FastAPI
* Зрение: чтение штрихкода (zxing) и цвет снимка (Pillow)
* База: SQLite
